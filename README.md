# SecureVPC

Secure AWS VPC and IAM security engineering project built with Terraform, Python, AWS IAM, CloudTrail, and GitHub Actions.

## Project Status

🚧 Work in progress

This repository is being developed as a practical cloud security and IAM engineering project.

## Objectives

- Build a secure AWS VPC using Terraform
- Implement IAM security controls
- Develop an automated IAM security auditor
- Enable AWS CloudTrail logging
- Develop security detections from CloudTrail events
- Implement GitHub Actions CI/CD
- Authenticate GitHub Actions to AWS using OIDC
- Apply least-privilege IAM principles
- Implement automated security validation

## Architecture

The project will eventually include:

- AWS VPC
- Public and private subnets
- Internet/NAT routing
- Security groups
- IAM roles and policies
- CloudTrail
- IAM security auditing
- GitHub Actions
- AWS IAM OIDC federation

## Security

This project is designed to demonstrate practical cloud security engineering, IAM governance, least privilege, identity federation, logging, monitoring, and automated security validation.

See [SECURITY.md](SECURITY.md) for security-related information.
